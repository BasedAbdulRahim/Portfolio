# Based Abdul Rahim — Portfolio

A responsive personal portfolio covering my software-engineering education, current technical toolkit, selected projects, work experience, and accomplishments.

## Pages

- `AboutMe.html` — professional overview and selected work.
- `LifeAndProgress.html` — a personal log for projects, learning, fitness, milestones, and daily life.

Open `AboutMe.html` in a browser to view the site. Journal entries are stored with browser `localStorage`; they stay on that browser and device unless its data is cleared. Use **Copy as HTML** to prepare an entry for permanent publishing.

Shared visual styles live in `styles.css`; journal behavior lives in `progress.js`.
